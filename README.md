# Introduction to Kubernetes with Grid-5000

This project is based on the practical exercises developed by Professor Daniel Balouek from the University of Nantes. It aims to introduce students to Grid-5000 and Kubernetes through hands-on exercices.

## TP1 – Introduction to Grid-5000

The first exercise serves as an introduction to the Grid-5000 platform and its various clusters. It allows me to become familiar with the environment and basic operations on the platform
[here](https://dbalouek1.gitlabpages.inria.fr/middleware-labs/).
## TP2 – Getting Started with Kubernetes

The second exercise focuses on learning the basics of Kubernetes using **Minikube** and **kubectl**. During this exercise, I am introduced to fundamental Kubernetes concepts such as:

- **Pods**  
- **Services**  
- **Deployments**  

This TP also includes the first deployment on Grid-5000. The goal is to develop a simple calculator application, containerize it, and deploy it on a Kubernetes platform. The tasks are as follows:  

1. Complete the file `<main-simple-calculator.js>` to implement the desired calculator functions.  
2. Upload the solution to **Docker Hub**.  
3. Create a deployment to test the application in another environment.  

## TP3 – Advanced Deployment and Autoscaling

The third exercise consolidates the knowledge acquired throughout the Middleware module. Students deploy an **autoscaler** capable of automatically adjusting to the load, applying all concepts learned in the previous exercises.

---

This series of exercises provides me a comprehensive introduction to Kubernetes and cloud deployment.
